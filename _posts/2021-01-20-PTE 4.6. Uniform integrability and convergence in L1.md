## Uniform integrability

If a random variable $X$ is integrable, $\int_{|X|\ge a} |X| dP < \epsilon$ for all $\epsilon > 0$ for large $a$ and vice versa. Intuitively, in order for a random variable to be integrable, integration of its tail part should be bounded for any small $\epsilon.$ Uniform integrability is defined accordingly.

<div class="definition" text="uniform integrability">
$(X_t)_{t\in T}$ is uniformly integrable if $\lim_a \sup_{t\in T} \int_{|X_t|\ge a} |X_t| dP = 0.$
</div>

If $X_t \le X$ for all $t\in T$ where $X$ is integrable, $(X_t)$ is uniformly integrable. If $(X_t), (Y_t)$ are uniformly integrable, then $(X_t + Y_t)$ is uniformly integrable since for given $a>0$

$$\begin{aligned}
&\int_{|X_t+Y_t|\ge a} |X_t+Y_t| dP \\
&\le \int_{|X_t|+|Y_t|\ge a, |X_t|\ge |Y_t|} |X_t|+|Y_t| dP \\
 &\;\;\;\;+ \int_{|X_t|+|Y_t|\ge a, |X_t| < |Y_t|} |X_t|+|Y_t| dP \\
&\le \int_{2|X_t|\ge a} 2|X_t| dP + \int_{2|Y_t|\ge a} 2|Y_t| dP.
\end{aligned}$$

The next theorem which sometimes is referred to as Vitali's lemma is about necessary and sufficient condition for uniform integrability.

<div class="theorem">
$(X_t)_{t\in T}$ is uniformly integrable if and only if the followings hold.<br>
(i) $\sup_{t\in T} E|X_t| < \infty.$ <br>
(ii) $\forall \epsilon>0,\exists\delta>0$ such that $\sup_{t\in T} \int_A |X_t|dP \le \epsilon$ for all $A\in\mathcal{F}$ where $P(A)\le\delta.$
</div>
<div class="proof"><br>
($\Rightarrow$) (i) is clear. Given $A \in \mathcal{F},$ $a>0,$
$$\begin{aligned}
&  \int_A |X_t| dP \\
&= \int_{A\cap\{|X_t|\ge a\}} |X_t| dP + \int_{A\cap\{|X_t|< a\}} |X_t| dP \\
&\le \int_{|X_t|\ge a} |X_t| dP + aP(A)
\end{aligned}$$
Thus $\sup_t \int_A |X_t| dP \le \epsilon/2 + a\delta.$<br>
($\Leftarrow$) Let $M = \sup_t E|X_t| < \infty,$ $a_0 = M/\delta.$ Since $P(|X_t|\ge a_0) \le E|X_t|/a_0 \le M/a_0 = \delta,$ $\sup_t \int_{|X_t|\ge a_0} |X_t| dP \le \epsilon.$
</div>

We state our main theorem of this subsection.

<div class="theorem" text="Vitali">
Suppose $X_n \to X,$ $X_n \in L^p,$ $p\ge 1.$ The followings are equivalent.<br>
(i) $(|X_n|^p)$ is uniformly integrable.<br>
(ii) $X_n \to X$ in $L^p.$ <br>
(iii) $E|X_n|^p \to E|X|^p < \infty.$ <br>
</div>
<details>
  <summary>
    expand proof
  </summary>
  
<div class="proof"><br>
((i)$\Rightarrow$(ii)) By Fatou's lemma, $E|X|^p \le \infty.$ $|X_n - X|^p \le 2^p(|X_n|^p+|X|^p)$ makes $|X_n-X|^p$ uniformly integrable. By the theorem, given $\epsilon>0$ there exists $\delta>0$ such that $\sup_{t\in T} \int_A |X_t|dP \le \epsilon$ for all $A\in\mathcal{F}$ where $P(A)\le\delta.$ There exists $N$ such that for all $n\ge N,$ $P(|X_n-X|^p \ge \epsilon) \le \delta.$ Thus
$$E|X_n-X|^p = E|X_n-X|^p\mathbf{1}_{|X_n-X|^p\ge\epsilon}  + E|X_n-X|^p\mathbf{1}_{|X_n-X|^p<\epsilon} \le 2\epsilon.$$
((ii)$\Rightarrow$(iii)) Trivial by $|\|X_n\|_p - \|X\|_p| \le \|X_n - X\|_p.$<br>
((iii)$\Rightarrow$(i)) Given $a\in\mathbb{R}$ such that $P(|X|^p=a)=0.$<br>
<b>claim:</b> $|X_n|^p\mathbf{1}_{|X_n|^p \le a} \overset{P}{\to} |X|^p\mathbf{1}_{|X|^p \le a}.$<br>
For all $\delta>0,$
$$\begin{aligned}
&P(|\mathbf{1}_{|X_n|^p \le a} - \mathbf{1}_{|X|^p \le a}|>\epsilon)\\
&\le P(|X_n|^p\le a, |X|^p>a) + P(|X_n|^p>a, |X|^p \le a) \\
&\le P(|X_n|^p\le a, |X|^p>a+\delta) + P(|X_n|^p>a, a-\delta < |X|^p \le a) \\
 &\;\;\;\;+ P(|X_n|^p > a, |X|^p \le a-\delta) + P(|X_n|^p>a, a-\delta < |X|^p \le a) \\
&\le 2P(||X_n|^p-|X|^p|>\delta) + P(a<|X|^p\le a+\delta) + P(a-\delta<|X|^p\le a)
\end{aligned}$$
Thus as $\delta\to0,$
$$\limsup_n P(|\mathbf{1}_{|X_n|^p \le a} - \mathbf{1}_{|X|^p \le a}|>\epsilon) \le 0 + P(|X|^p = a) = 0.$$
By the claim and since $|X_n|^p\mathbf{1}_{|X_n|^p\le a}$ is bounded by $a,$ $(|X_n|^p\mathbf{1}_{|X_n|^p\le a})$ is uniformly integrable. By (i)$\Rightarrow$(ii)$\Rightarrow$(iii), $E|X_n|^p\mathbf{1}_{|X_n|^p \le a} \to E|X|^p\mathbf{1}_{|X|^p \le a}.$ In addition, by the assumption $E|X_n|^p\mathbf{1}_{|X_n|^p > a} \to E|X|^p\mathbf{1}_{|X|^p > a}.$
For a given $\epsilon>0,$ there exists $a_0>0$ such that $E|X|^p\mathbf{1}_{|X|^p > a_0}<\epsilon/2$ and $P(|X|^p=a_0)=0.$ Pick $N$ such that $\left|E|X_n|^p\mathbf{1}_{|X_n|^p > a_0} - E|X|^p\mathbf{1}_{|X|^p > a_0}\right| < \epsilon/2$ for all $n\le N.$ Then for $n\ge N,$ $E|X_n|^p\mathbf{1}_{|X_n|^p > a_0} < \epsilon.$ For $n < N,$ there exists $a_1$ such that $\max_{n<N} E|X_n|^p\mathbf{1}_{|X_n|^p > a_0} < \epsilon.$
</div>
</details>

## $L^1$ convergence of martingales
With uniform integrability we get $L^1$-convergence of martingales. First we define regular and closable martingale for simplicity of the statement.

<div class="definition"><br>
A martingale $(X_n)$ is regular if there exists a random variable $X \in L^1$ such that $X_n = E(X|\mathcal{F}_n)$ a.s.<br>
A martingale $(X_n)$ is closable if there exists a random variable $X_\infty \in L^1$ such that $X_n \to X_\infty$ a.s. and $E(X_\infty | \mathcal{F}_n) = X_n$ a.s. for all $n.$
</div>

If $X_n$ is closable, then it is clearly a regular martingale.

<div class="theorem" text="4.6.7">
Let $X_n$ be a martingale. The followings are equivalent.<br>
(i) $X_n$ is regular. <br>
(ii) $X_n$ is uniformly integrable. <br>
(iii) $X_n$ converges a.s. and in $L^1$ <br>
(iv) $X_n$ is closable. <br>
</div>
<details>
  <summary>
    expand proof
  </summary>
   
<div class="proof"><br>
((i)$\Rightarrow$(ii)) There exists $X \in L^1$ such that $X_n = E(X|\mathcal{F}_n)$ a.s.
$$\int_{|X_n|\ge a}|X_n|dP \le \int_{|X_n|\ge a} E(|X||\mathcal{F}_n)dP \le \int_{E(|X||\mathcal{F}_n)\ge a}|X|dP.$$
Since $X$ is integrable, for a given $\epsilon>0$ there exists $\delta>0$ such that $\int_A |X|dP < \epsilon$ for all $A$ such that $P(A)\le\delta$ and there exists $a>0$ such that $P(E(|X||\mathcal{F}_n)\ge a)\le \frac{1}{a} E|X| < \delta.$<br>
((ii)$\Rightarrow$(iii)) Uniform integrability implies $\sup_n |X_n| < \infty$ so by submartingale convergence we get convergence in probability. By Vitali's lemma, we get the result.<br>
((iii)$\Rightarrow$(iv)) There exists $X \in L^1$ such that $E|X_n-X|\to0$ as $n\to\infty.$ Then $E|X_n| \to E|X|$ and $\sup_n E|X_n| <\infty.$ By submartingale inequality, there exists $X_\infty \in L^1$ such that $X_n\to X_\infty$ a.s. Notice that $X=X_\infty$ a.s. Let $m \ge n$ then
$$\begin{aligned}
&E\left| E(X_\infty|\mathcal{F}_n) - X_n \right| \\
&= E\left| E(X_\infty|\mathcal{F}_n) - E(X_m|\mathcal{F}_n) \right| \\
&\le E\left| E(|X_\infty - X_m| | \mathcal{F}_n) \right| \\
&= E|X_\infty - X_m| \to 0
\end{aligned}$$
as $m\to\infty.$ Hence $E(X_\infty|\mathcal{F}_n) = X_n$ a.s.<br>
((iv)$\Rightarrow$(i)) Trivial.
</div>
</details>
